## Product Description:
A digital book exchange and lending system that enables users to list books available for lending or exchange. The system allows users to search for books by author, genre or course and also track lending status, return deadlines and borrower ratings. Below are listed essential product features:

## User Accounts / Profiles
Book Listings
Search / Filter
Lending / Exchange Requests
Lending Status Tracking
Return Deadlines
Borrower Ratings

## Need and Value:
This product lets people exchange, lend or borrow books. Users who want to lend books will find more suitable and safe candidates thanks to the ability to rate borrowers. Users searching to borrow books will have a trusted source at no financial cost. Existing solutions focus on buying or selling books rather than lending or exchanging. This makes for a more convenient and trustworthy source for people seeking to lend/borrow books.
Stakeholders:
Book owners, Book borrowers, Readers, Students, Professors, Teachers, Collectors, Professionals, Community members, Libraries, Educational organizations
Technology Requirements:

Frontend: JavaScript React
Backend: Python Django DRF
Database: SQLite

installation instructions:
### Backend

install django and the rest framework

> pip install django

> pip install djangorestframework

go to backend directory to run
> cd backend

run backend
> python manage.py runserver

### Fontend
install npm
> npm install

go to frontend directory to run
> cd frontend

run frontend
> npm run dev
